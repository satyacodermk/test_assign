📊 Project Overview & User Flow
Project Overview:
The Interactive Quiz & Learning App is a terminal game. Users read a question, type the number of the option they think is right, and get instant feedback. At the end, they see a full score summary and can play again or quit. The purpose is to practise the fundamentals of JavaScript by building something fun and complete, with no HTML, CSS, or database involved.

User Flow:
The user launches the app and sees the welcome message, the rules, and a Start/Exit menu
The user chooses to start, and the program loads the questions and sets the score to zero
The program shows the current question with its numbered options
The user types an option number, and the program rejects invalid input and asks again until it is valid
The program checks the answer, then displays "Correct" or "Incorrect" (plus the right answer) and updates the score
After the last question, the program calculates the percentage and displays the results with a performance message
The user chooses to play again or exit, and the program restarts the quiz or says goodbye
